# mjs module
This module provide fundamental APIs that operate directly on uncompiled models and results in MuJoCo's `mjSpec` structures. These APIs are helpful for editing models while maintaining the editability of the resulting outputs. APIs here can be sequenced. Once all adaptation are in place, a compile step is required to get to compiled MjModel.

Navigate to individual folders for API and functionality details.

For fundamental tools to edit and operate on on MuJoCo's **compiled** `MjModel` and `MjData` data structures, refer to [mj section](../mj/)
