
# Tensor Operations

A utility module for tensor manipulation and operations within the MyoLab framework.

## Overview

This module provides commonly used tensor operations for working with neural network computations and data transformations.


- Efficient tensor operations
- NumPy and PyTorch compatibility
- Common data transformation utilities

## Features

- [dict_utils.py](dict_utils.py) implements a series of utilities to manipulate dictionaries, including functions to convert dictionary values to numpy arrays, print the data types of dictionary values, flatten nested dictionaries, and unflatten flattened dictionaries.
- [quat_utils.py](quat_utils.py) implements a mujoco and myo_tools compatible quaternion algebra library.
- [tensor_utils.py](tensor_utils.py) implements various utility functions for tensor operations, including flattening, unflattening, padding, stacking, concatenating, splitting, and truncating tensors and dictionaries of tensors.
